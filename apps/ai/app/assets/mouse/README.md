# Clics de souris enregistrés (team 12, Amine K.)

7 extraits de 0,45 s (`m01.mp3` … `m07.mp3`), chacun centré sur un clic (appui, ou appui + relâchement), tirés d'un
enregistrement de souris choisi par l'équipe (« mouse.mp3 », 7 s). Même format que la voix (mono, 44,1 kHz,
128 kb/s, sans en-tête), normalisés à −32 LUFS (`loudnorm=I=-32:TP=-4`), départs 1,02 / 1,85 / 2,10 / 3,56 / 4,50 /
5,38 / 6,31 s. Un extrait sur quatre pendant l'attente (`services/fillers.keep_typing`).
